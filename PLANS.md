# Where Emaki is heading

Hi. I'm Arthur, and I make Emaki.

Emaki works. It installs, also next to Windows. It updates and rolls back from the boot menu when
something goes wrong. Programs & Updates installs programs from Arch, Flathub and the AUR. The shell
has a light and a dark theme, accent colours, and works with the keyboard. Since 0.12 it speaks
English, Spanish, Portuguese, German, French and Russian.

Why a beta now. Until recently Emaki had only run on my own machines, and the plan was simple: once
it runs on other people's computers, it is no longer an alpha. That has happened. Our update server
shows more than a dozen systems in about ten countries, installed by other people, that keep
checking for updates. The server only counts the requests and knows nothing about you. So far
nobody has come back with a broken system. The alpha was for getting here. The beta is for finding
what still breaks on hardware I haven't seen.

0.12 is the last alpha. The first beta, 1.0, starts with something Emaki has needed for a while: it
gets lighter. Before adding more, I will measure what each part costs on its own — the glass, the
moving wallpaper, every part of the bar, the helpers that run in the background — and then either
make the expensive parts cheaper or let you switch them off if you don't need them.

With the beta, Emaki is also open for you to take part. Suggest a change, report a bug or fix a
translation: everything goes through the public repository, and I take it in. Translations are the
easiest place to start. Emaki now speaks six languages, and I don't speak most of them natively, so
if a sentence in your language sounds wrong, send a better one.

What beta means here. Everything works, and I use Emaki every day on my own laptop. Every update can
be rolled back from the boot menu. But I can't test every computer, and on hardware I haven't seen
things can still break. Two cases are not tested yet at all: real NVIDIA cards, and installing next
to a Windows that uses BitLocker. If that is your machine, try Emaki from the USB stick first, and
back up before you install next to Windows.

So the request stays the same: install Emaki, use it, and tell me what broke. "Report a problem" is
right in the system.

Why Arch. Emaki is built on Arch Linux because Arch is what I use every day.

These are not promises, just my thoughts on where we are going. This text will change along with
the project.

— Arthur
