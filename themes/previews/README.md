# Catalog previews

Small previews of the Emaki cube strip and eighteen colour strips. The catalog
explicitly assigns the **Rose** accent to the Emaki cube theme. It
uses these when the separately packaged media is absent. Images are centre crops
generated by `scripts/prepare-theme-assets`. The checked-in JPEGs carry copyright
and licence comments added separately; the staging script does not add those
comments. Full-size strips and videos are external package inputs.

The eighteen ribbon previews now come from the error-diffused RGB8 variant A
shipping strips (`ship-a-2160`), regenerated by `art/ribbons/prepare_shipping.py`
with the same crop/scale command and JPEG licence comment. The Emaki cube
preview is retained. Strip provenance is recorded in `art/ribbons/README.md`
and `art/ribbons/SHA256SUMS`.
